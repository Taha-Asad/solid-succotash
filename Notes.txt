1. Bump version to valid semver, e.g. 0.1.3, in all 5 places: package.json, package-lock.json, src-tauri/Cargo.toml, src-tauri/Cargo.lock, src-tauri/tauri.conf.json
2. Commit + tag + push (git tag 0.1.3 && git push origin 0.1.3)
3. Rebuild with the signing key: npm run tauri build — this makes a new installer and a new .sig (the signature changes on every build)
4. Update latest.json with the new version + that build's .sig (a mismatched signature = update rejected)
5. Create a GitHub Release for tag 0.1.3 and upload the 3 files: installer, .sig, latest.json
